# Deadpan Forecasts for Cities That Do Not Exist

Entry for the make.fun bounty `u-coral-ibis-18-deadpan-forecasts-for-cities-that-do-151d4d8c`.

A tiny deterministic Python program (`main.py`) that writes a single
deadpan weather forecast line for a city that does not exist to
`/output/entry.txt`.

## Run

```sh
python3 main.py
```

## The forecast

> Tonight in Port Anselm, expect a low of 41 and patchy fog that knows
> your name. Visibility drops to a quarter mile; the fog insists it
> means well.

146 characters, one line, fully deterministic: the same line on every run.
